# Visualizaciones estratégicas
Strategy Execution Map conecta objetivos con iniciativas y riesgo. Portfolio Flow Map expone volumen, aging, riesgo, capacidad y bloqueos. Strategy-to-Capacity compara target, compromiso y consumo. Outcome Progress compara actual, forecast, confianza y target. Cada visual incluye pregunta, interpretación, fuente, actualización, cobertura y evidencia.
