# FlowOS Enterprise Platform 3.0
FlowOS es la capa de inteligencia ejecutiva sobre Atlassian para Deuna Ecuador. Conserva el monolito modular: UI, APIs backend, reglas, adaptadores read-only, Snapshot Engine y Prisma. El contexto organizacional aísla datos por `organizationId`; el modo actual es DEMO y prepara evolución controlada a LIVE.
