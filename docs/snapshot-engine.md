# Snapshot Engine
Desacopla la navegación de las consultas Jira. Soporta FULL, INCREMENTAL, MANUAL y SCHEDULED; checkpoints por organización/fuente, deduplicación, idempotencia, historial de Sync Runs, errores parciales, cobertura y fallback al último snapshot válido. `DemoSnapshotEngine` ejecuta simulaciones coherentes locales; no incluye scheduler cloud.
